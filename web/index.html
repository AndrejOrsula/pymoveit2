    About

    Nothing here talks to ROS: a small JavaScript stand-in for MoveIt 2 plans, checks collisions and executes trajectories, so plans and timings differ from a real run. The Python is pymoveit2's real API; on a robot, the same code talks to move_group. The Panda is configured as moveit_resources_panda_moveit_config, the OpenMANIPULATOR-X as in open_manipulator-RMinS.

    Panda meshes: franka_description, Apache-2.0, Copyright 2023 Franka Robotics GmbH; decimated. OpenMANIPULATOR-X meshes, URDF and MoveIt configuration: open_manipulator-RMinS, Apache-2.0, Copyright ROBOTIS CO., LTD.; decimated. 3D rendering: three.js, MIT. Python in the browser: Pyodide, MPL-2.0, loaded from jsDelivr only when you run a script. Font: Inter, OFL-1.1. Bundled licenses.
